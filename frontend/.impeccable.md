# Impeccable Design Context — ref-ai.ru

## Design Context

### Users
Студенты российских вузов, преимущественно в состоянии дедлайна — им нужна работа сегодня.
Вторичная аудитория: те, кто планирует заранее и хочет сэкономить время.
Контекст использования: мобильный/ноутбук, вечер перед сдачей, высокий стресс.
Job-to-be-done: получить готовый DOCX по ГОСТу, сдать, чтобы приняли.

### Brand Personality
Три слова: **надёжно · быстро · по-ГОСТу**
Тон: уверенный и деловой, без панибратства. Как хороший старший однокурсник —
не преподаватель, не стартап-чат-бот. Компетентный, конкретный, без лишних слов.
Эмоциональная цель: **доверие**. Студент должен почувствовать — здесь не обманут,
работу примут, оформление правильное.

### Aesthetic Direction
Визуальный тон: уверенный минимализм с академическим весом. Не playful, не neon-AI.
Ближе к premium SaaS с академическим авторитетом — чистый, структурированный, весомый.

Референсы:
- marsik.ai — хорошее общее ощущение (чисто, профессионально)
- retext.ai/ru — нравится структура и читаемость layout

Антиреференсы / что запрещено:
- Дешёвый AI-след: cyan-on-dark, purple-to-blue градиенты, glow-эффекты
- Загроможденность — каждый элемент должен дышать
- Плохая адаптивность — мобайл первичен
- Непонятность — CTA должны быть очевидны без раздумий
- Банальный indigo/violet `#6366F1` — самый заезженный AI-цвет 2024

Тема: **тёмный hero + светлый контент** (текущий паттерн верный, но цвета надо пересмотреть)

### Design Principles
1. **Доверие через детали** — правильные отступы, чёткая типографика, никаких ошибок в UI
2. **Ясность важнее красоты** — каждый блок отвечает на вопрос "что мне делать дальше?"
3. **Академический вес без скуки** — серьёзный тон, но не казённый
4. **Мобайл как главный экран** — большинство придут со смартфона в панике
5. **Никакого AI-слопа** — если UI выглядит как шаблон из ChatGPT-wrapper — переделать

### Color Direction
Уйти от `#6366F1` (indigo). Рассмотреть:
- Тёмно-синий/navy с тёплым акцентом (янтарь, терракота) — академичность + тепло
- Или глубокий slate + чистый белый + один сильный акцент

### Typography Direction  
Избегать Inter, DM Sans и стандартных AI-шрифтов.
Искать что-то с академическим характером но современное.
